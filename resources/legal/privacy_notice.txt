Data stored locally
- The application stores settings, download/task metadata, and playlist/item records in a local SQLite database under: %LOCALAPPDATA%\VeloDownloader
- The application writes logs under: %LOCALAPPDATA%\VeloDownloader\logs
- Cache/temporary data may be stored under: %LOCALAPPDATA%\VeloDownloader\cache and %LOCALAPPDATA%\VeloDownloader\temp
- Downloaded media files are saved to the user-selected output folder (default is typically under the user's Downloads folder unless changed in Settings).

Information that may be stored
- URLs you enter, extracted metadata (e.g. titles, thumbnails URLs, formats), task status/progress, file paths, timestamps, and error messages.

Network and third parties
- When you request metadata extraction or a download, the application connects to the relevant external source/service using yt-dlp to retrieve information and content you requested.
- The application does not include built-in analytics/telemetry or automatic update checks in the current baseline.

User responsibilities
- Use the application only for content you are authorized to access and save, and comply with applicable laws and source/platform terms.
